# Awesome Telugu [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources for the Telugu language, its literature, culture and technology.
>
> తెలుగు నేర్చుకోవాలన్నా, చదవాలన్నా, రాయాలన్నా, తెలుగులో ఏదైనా నిర్మించాలన్నా, కావలసిన మంచి వనరులన్నీ ఒకే చోట.

Telugu is a Dravidian language spoken by more than 80 million people, mainly in Andhra Pradesh and Telangana. This list collects what is most useful for learners, readers, writers, designers, developers and researchers.

(Open Telugu) marks sites by the maintainers of this list. You can also browse the list, with search, at [awesome.opentelugu.org](https://awesome.opentelugu.org/).

## Learning

### Courses and Lessons

- [Mana Badi](https://manabadi.siliconandhra.org/) - Silicon Andhra's Telugu classes, held online and across the USA.
- [I Love Languages](https://www.ilovelanguages.org/telugu.php) - Free lessons with vocabulary, grammar and useful phrases.
- [50LANGUAGES](https://50languages.com/learn-telugu-easily-and-fast) - Topic-based lessons for beginners with free audio.
- [Telugu on Wikibooks](https://en.wikibooks.org/wiki/Telugu) - Open textbook that anyone can edit.
- [FreeLanguage.org](https://freelanguage.org/learn-telugu) - Directory of free learning material.

### Grammar

- [An Introduction to Telugu Grammar](https://www.cs.ucdavis.edu/~vemuri/Grammar/0.%20preface.pdf) - Free modular course by V. Vemuri, in Roman transliteration and Telugu script.
- [An Intensive Course in Telugu](https://archive.org/details/in.ernet.dli.2015.373515) - Scanned course by P. Ramanarasimham from the Digital Library of India.
- [A Grammar of Modern Telugu](https://casbs.stanford.edu/grammar-modern-telugu) - Reference grammar by Bhadriraju Krishnamurti and J. P. L. Gwynn. Published book, not a free download.

### School Textbooks

- [SCERT Telangana](https://scert.telangana.gov.in/) - State council responsible for Telangana's school curriculum and textbooks.

### Script and Encoding

- [Telugu Unicode Chart](https://www.unicode.org/charts/PDF/U0C00.pdf) - Official code chart for the Telugu block.
- [Telugu Orthography Notes](https://r12a.github.io/scripts/telu/te.html) - Technical notes on the writing system for implementers.
- [Indic Layout Requirements](https://www.w3.org/TR/ilreq/) - W3C guidance on laying out Indic scripts.
- [Telugu Script on Wikipedia](https://en.wikipedia.org/wiki/Telugu_script) - History and structure of the writing system.

## Dictionaries

- [Gwynn's Telugu-English Dictionary](https://dsal.uchicago.edu/dictionaries/gwynn/) - Searchable modern dictionary, hosted by Digital Dictionaries of South Asia.

- [Bharatavani](https://bharatavani.in/) - Multilingual knowledge portal from the Central Institute of Indian Languages.

## Literature

### Digital Libraries

- [Vaidika Vignanam](https://vignanam.org/telugu.htm) - Vedic chants, stotras and the Bhagavad Gita in Telugu script.
- [Stotra Nidhi](https://stotranidhi.com/) - Large collection of stotras in Telugu script.
- [Sri Vaddiparti Padmakar](https://srivaddipartipadmakar.org/) - Telugu discourses on the eighteen Puranas, the minor Puranas and the epics.
- [Telugu Bible](https://github.com/FreeBiblesIndia/Telugu_Bible) - Openly licensed text under CC BY-SA 4.0.

## AI Agents and MCP

### MCP Servers

No Telugu-only [Model Context Protocol](https://modelcontextprotocol.io/) server is listed yet. These servers wrap general Indic language APIs.

- [Sarvam MCP](https://github.com/sarvamai/sarvam-mcp) - Official server for Sarvam's speech, translation, transliteration and OCR APIs ([docs](https://docs.sarvam.ai/api/developer-tools/mcp)).
- [sarvam-mcp-server](https://github.com/Shobhit-Nagpal/sarvam-mcp-server) - Community server for the Sarvam APIs.
- [Devnagri Translate MCP](https://github.com/DevnagriAI/devnagriai-translate-mcp) - Translation server focused on Indic languages.

### Agents

- [Telugu Agentic RAG](https://github.com/DIVYANSH-TEJA-09/telugu-agentic-rag) - Multi-agent storytelling system with a planner, drafter and critic loop.
- [Telugu LLM Probe](https://github.com/kishore-ayyadevara/telugu-llm-probe) - Measurement log for building a Telugu assistant on Gemma, including a tool-use dataset.
- [Saaram](https://github.com/HariN999/Saaram-telugu-summarizer) - Telugu news summarization with speech output.

### Voice Agents

- [Telugu Phone Voice Agent](https://github.com/vthiruveedhi/voice-agent) - Real-time phone agent built with Twilio, faster-whisper, Ollama and edge-tts.
- [Telugu and English Voice Agent](https://github.com/gowtham2891/telugu-voice-agent) - Real-time agent for code-mixed speech, built on Sarvam's speech models.
- [Telugu Voice Agent Prototype](https://github.com/bodavulasiddardha-png/telugu-voice-agent) - Inbound agent on Bolna with a self-hosted Telugu voice.
